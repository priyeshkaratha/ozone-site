# Directory Configurations for Datanodes

This section describes the directory-related configuration properties used by Ozone Datanodes (DN).

| Property Name                                      | Description                                                                                                                                                                                                                                   | Tags                                             | Default/Example Value                                                   | Sample Value                      |
| -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ | ----------------------------------------------------------------------- | --------------------------------- |
| `hdds.datanode.dir`                                | Comma-separated list of directories where HDDS data volumes are stored. Directories can be tagged with storage types: `[SSD]`, `[DISK]`, `[ARCHIVE]`, or `[RAM_DISK]`. Untagged directories default to `DISK`.                               | OZONE, CONTAINER, STORAGE, MANAGEMENT            | Empty (creates directory if it doesn't exist)                           | `/data/hdds`                      |
| `hdds.datanode.data.dir.permissions`               | Permissions for Datanode data directories where file blocks are stored. Octal or symbolic format.                                                                                                                                             |                                                  | `700`                                                                   | `700`                             |
| `hdds.datanode.container.db.dir`                   | Directory where per-disk RocksDB instances are stored. If not set, RocksDB is co-located on the same disk as HDDS data. Supports storage type tags. Ideally mapped to fast storage like SSD.                                                 | OZONE, CONTAINER, STORAGE, MANAGEMENT            | Falls back to `hdds.datanode.dir` if undefined                          | `/var/data/ozone/datanode/db`     |
| `hdds.container.ratis.datanode.storage.dir`        | Directory for storing Ratis (Raft) log metadata on Datanodes. Ideally mapped to fast storage like SSD. Falls back to `ozone.metadata.dirs` with a warning if not set.                                                                        | OZONE, CONTAINER, STORAGE, MANAGEMENT, RATIS     | Falls back to `ozone.metadata.dirs` if undefined                        | `/var/data/ozone/datanode/ratis`  |
| `ozone.scm.datanode.id.dir`                        | Directory where the Datanode persists its `datanode.id` file. The directory is created if it does not exist. Falls back to the metadata directory if unset.                                                                                   | OZONE, MANAGEMENT                                | Falls back to `ozone.metadata.dirs` if undefined                        | `/var/data/ozone/datanode`        |
| `hdds.datanode.dir.du.reserved`                    | Space reserved per volume and excluded from Ozone usage. Specified as a comma-separated list of `<path>:<size>` pairs (e.g. `/data/hdds:100GB,/data2/hdds:50GB`).                                                                            | OZONE, CONTAINER, STORAGE, MANAGEMENT            | Empty                                                                   | `/data/hdds:10GB`                 |
| `hdds.datanode.dir.du.reserved.percent`            | Percentage of each volume's total capacity to reserve and exclude from Ozone usage. Value between `0` and `1` (e.g. `0.1` = 10%).                                                                                                            | OZONE, CONTAINER, STORAGE, MANAGEMENT            | Empty                                                                   | `0.1`                             |
| `hdds.datanode.failed.data.volumes.tolerated`      | Number of data volumes allowed to fail before the Datanode stops serving requests. `-1` means unlimited (at least one good volume must always remain).                                                                                        | DATANODE                                         | `-1`                                                                    | `1`                               |
| `hdds.datanode.failed.metadata.volumes.tolerated`  | Number of metadata volumes allowed to fail before the Datanode stops serving requests. `-1` means unlimited.                                                                                                                                  | DATANODE                                         | `-1`                                                                    | `1`                               |
| `hdds.datanode.failed.db.volumes.tolerated`        | Number of DB volumes allowed to fail before the Datanode stops serving requests. `-1` means unlimited.                                                                                                                                        | DATANODE                                         | `-1`                                                                    | `1`                               |
| `hdds.datanode.disk.balancer.info.dir`             | Directory where the Disk Balancer writes its configuration and state files. Falls back to the metadata directory if unset.                                                                                                                     | DISKBALANCER                                     | Falls back to `ozone.metadata.dirs` if undefined                        | `/var/data/ozone/datanode`        |
